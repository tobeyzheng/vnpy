# Practical Scoring V1

This version is intended to replace pure rule-template scoring with a more practical hybrid model.

## Dimensions
- market_trend
- liquidity
- catalyst
- fundamentals
- skill_consensus
- agent_judgment
- execution_fit
- risk_penalty

## Inputs
The model is designed to consume normalized evaluation signals from:
- real candidate providers
- watchlist realtime data
- stock-related skills
- knot agent evaluations

## Goal
Keep scoring explainable while allowing multi-source practical judgment.
