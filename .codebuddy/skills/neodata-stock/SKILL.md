# NeoData 股票/指数/板块数据查询

NeoData 股票指数板块查询服务，面向股票/指数/板块的一体化数据查询能力，输入自然语言 query，返回 JSON 格式的结构化金融数据。

## 服务端点

- **Host**: `https://lily-pre.woa.com`
- **URI**: `/neodata/stock`
- **鉴权**: 无需鉴权

## 调用方式

> 优先使用 Python 脚本，仅当 Python 不可用时使用 Shell 脚本（curl 封装）。

**Python（推荐）**：
```bash
python scripts/query.py --query "腾讯控股今日主力资金净流入"
python scripts/query.py --query "沪深300最新行情"
python scripts/query.py --query "创业板指近一个月走势" --sub-channel openclaw
```

**Shell（备选）**：
```bash
bash scripts/query.sh "腾讯控股今日主力资金净流入"
bash scripts/query.sh "创业板指近一个月走势"
```

## 请求参数

| 字段 | 必填 | 说明 |
|------|------|------|
| `channel` | 否 | 渠道信息，固定值 `neodata`，无需传入 |
| `sub_channel` | 否 | 子渠道信息，默认 `openclaw` |
| `query` | 是 | 自然语言查询 |
| `request_id` | 是 | 请求唯一 ID，用于链路追踪 |
| `se_params` | 否 | 搜索引擎预留参数 |
| `extra_params` | 否 | 扩展预留参数 |

## 响应结构概览

成功时 `code` 为 `"200"`，`suc` 为 `true`，核心数据在 `data` 中：

- **`data.apiData.entity`** - 命中标的列表（股票代码与名称）
- **`data.apiData.apiRecall`** - API 内容块列表，每块含 `type`、`desc`、`content`、`tag`
- **`data.docData`** - 文本召回结果（可能为 null）

## 市场覆盖范围

- **股票市场**：A股（沪深）、港股、美股、日股、韩股
- **板块市场**：A股行业板块、概念板块、地域板块
- **指数市场**：全球主要指数（含上证、深成指、恒指、标普500、纳指、道指、日经225等）

## 数据覆盖范围

### 1) 行情与历史走势（股票/指数/板块）
- **实时行情**：最新价、涨跌幅、成交量/额、市值、盘口等
- **历史走势**：成交量/额、区间涨跌幅与振幅

### 2) 技术指标
- 多周期均线（5/10/20/30/60/120/250）
- MACD、布林带、KDJ
- 量能与强弱类指标（如量比、VR、AR/BR、ADX 等）
- 支持当日实时计算与历史回溯（历史指标按 T+1 更新）

### 3) 资金与交易行为
- **资金流向**：当日与历史（主力/散户净流入、流入流出拆分、分单结构等），含板块主力净流入排名
- **龙虎榜（A股）**：上榜天数、原因、净买入、买卖营业部等
- **融资融券（A股）**：融资融券差额、主力净流入、历史日度序列
- **大宗交易（A股）**：近 60 日总量/总额、折溢价特征与明细
- **港股通与卖空（港股）**：港股通持股比例/变动、卖空占比与卖空股数

### 4) 公司基本信息与基本面
- **公司基本资料**：公司简介、上市信息（上市日期、发行价格）、主营业务描述
- **行业与概念归属（A股重点）**：一级/二级行业、概念板块归属；并提供行业实时表现与成分分布统计
- **业务结构与业绩趋势**
  - 主营业务构成：业务线/产品维度收入明细与占比
  - 历史业绩趋势（A股）：历年收入、净利润、EPS 等
  - 经营指标：按指标名称与时间范围查询历史披露经营指标明细

### 5) 财务报表与综合财务指标
- **综合财务指标**：盈利/偿债/营运/成长四维度核心比率，提供 TTM 与同比等
- **三大报表**
  - 资产负债表：资产结构、负债结构、所有者权益
  - 利润表：收入、成本费用、利润与损益结构（单季/累计）
  - 现金流量表：经营/投资/筹资现金流与关键净额指标

### 6) 估值与行业对比（A股）
- 个股估值：PE、PB、PE 历史分位等
- 财务健康与行业对比排名（盈利/成长/运营/偿债等）
- 盈利能力行业对比：行业均值、行业龙头对照、个股市场表现等维度

### 7) 股东、分红回购与股权结构
- 股本结构、股东人数、人均持股
- 大股东与主要股东持股占比、股东分布
- 高管职务信息
- A股机构持仓统计
- 分红送配与派现募资比等

### 8) 事件、风险与交易日信息
- **财务披露提醒**：业绩快报、预告、预计披露时间、披露事件
- **股权/股本变动与分红事件**：拆并股、增发、解禁、质押、解除质押、高管增减持、股东人数变化等
- **公司运营与交易提醒**：收购、龙虎榜、大宗、两融、新股上市、停复牌、股东大会等
- **风险与监管（A股重点）**：破净/破发、可转债到期与强赎、ST/退市、监管问询、诉讼仲裁等
- **交易日信息**：市场开市/休市安排；个股交易日/停牌等

### 9) 投研与资讯
- **机构观点与一致预期**：研报评级统计、目标价区间、盈利预测（EPS/净利/收入及同比）、行业对比
- **文本类解读**
  - 财报文本分析：经营/行业环境/风险/战略等维度摘要
  - 公司研报与行业研报：公司基本面、财务、竞争与建议；行业定义、产业链、规模、竞争、供需、展望等
- **财经资讯**：覆盖股票/板块/指数/基金/宏观等，多类型新闻与快讯（含正负面舆情与重大事件）

### 10) 市场与板块视角（统计、榜单、热点、成分）
- 大盘估值（上证/深证/创业板）与两市当日统计（成交、涨跌家数、涨跌停、停牌等）
- A股/港股/美股日度交易排行榜（个股/板块多维排名）
- 板块主力统计与领涨股、板块当日异动与成分股
- 板块热点原因、板块估值（PE/PB）
- 行业/板块成分股；以及相关场内 ETF、场外基金列表（按板块维度）

## 何时使用本 Skill

当用户问题主要与"股票、指数、板块"的研究、交易监测或复盘相关时优先使用，例如：
- **个股研究**：公司概况、业务结构、财务报表、综合财务指标、估值与行业对比、机构一致预期
- **板块/主题跟踪**：板块涨跌、资金主力、热点原因、成分股分布与领涨结构、板块估值
- **盘中监测与交易行为分析**：实时行情、技术指标、资金流向、龙虎榜/两融/大宗等交易行为
- **事件驱动与风险管理**：业绩披露、解禁/质押/增减持、停复牌、监管与风险提示
- **市场复盘**：大盘统计、榜单扫描、热点归因、跨市场对照

详细的响应字段说明与示例见 [reference.md](reference.md)。
